# 1.2.1 本地试用版

本版本仅供本机试用，未上传源码、未发布 Windows 压缩包或安装包；等待用户确认后再发布。

- OpenAI 设置简化为粘贴密钥、点击「连接并使用」。自动读取模型列表，发送简短请求验证连接，成功后加密保存。
- 服务名称自动生成；已有 OpenAI 服务可从实际模型列表切换模型。
- 其他服务和手动地址、模型配置保留在「其他服务 / 高级设置」。
- 区分模型不存在、接口地址不匹配、授权及额度错误，去除界面中冗长的内部调用报错前缀。
- 连接失败不替换原有配置。真实记录、图片和布局沿用本机数据。

本次范围仅包含 AI 连接体验和报错说明，不修改银行活动规则。
