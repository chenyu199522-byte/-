# 金羊毛 1.2.0

- 活动可添加多张截图，查看与导出原始图片，保存 offer 和客服沟通证据。
- 增加推荐链接，保留已有的关户来源信息。
- 新增 DD 条件检测的九个参考网站，以及论坛与指南入口。
- 编辑布局可以自定义软件名称，首页和窗口标题同步更新。
- 新增信用卡消费记录及独立进度条，支持逐期与一次性消费条件。
- 可配置多家 AI 服务。DD 查询带入记录中的来源备注，展示可核对依据；未查到时明确待核实。
- 粘贴银行活动链接，后台读取动态网页并生成表单草稿。不同奖励档位分开展示，选择后填写，保留来源、查询时间及网页原文。
- 存款金额与持有时间双进度，支持存足后计时或开户日固定期限；合格交易次数独立记录。
- 第二排右侧增加规则与提醒，宽屏并排、小窗口换行，长细则可展开。
- 支持存款与 DD 分项奖励、分别到账，以及达标当月月底起算的奖励期限。
- 所有记录在本机；初次打开为空白，分享包不含个人记录或密钥。

下载 ZIP 完整解压运行，或使用 Windows x64 安装程序。无需配置 AI 也能手动记录。

参见 [功能介绍](../../README.md) 和 [验证记录](../qa/1.2.0.md)。
