# 金羊毛

独立的 Windows 银行活动记录 App。首次打开是空白记录，无需注册。可以记录开户、工资直接存款（DD）、借记卡消费、免月费条件、奖励到账、关户与再次参加资格。按期达标、工作日和到账日期沿用金羊毛既有规则。长期活动可分别记录收益、存入和提取。

## 下载使用

在 [Releases](https://github.com/chenyu199522-byte/-/releases/latest) 下载 Windows x64 压缩包，**完整解压到一个文件夹**后运行其中的「金羊毛.exe」。也可以下载安装程序创建快捷方式。两种方式在同一 Windows 用户下使用同一份记录。

1. 点击「新增奖励活动」，填入银行和活动条件，保存。
2. 在活动的「…」中选择「记录开户」，再用「管理 DD」或「按月核对」逐笔添加记录。
3. 银行实际发奖后选择「奖励到账」。长期活动在「长期活动」中登记逐笔明细。

## 窗口与布局

默认按窗口可用宽高等比例缩放整个界面，以 1440×900 的内容区为参考，自动倍率为 85%–160%。到达下限后，窄窗口继续使用换行、精简列和局部滚动。Windows 显示缩放由系统先行处理。

在首页点「编辑布局」可以切换自动缩放。页面可调整字号、外边距与区域间距。统计卡片可逐项显示、隐藏、换序和调整最小宽度。活动表格可调整行高、各列宽度与顺序，并选择显示哪些列。机构和操作入口始终可用。修改可即时预览，点击「保存布局」后在本机生效；「取消」放弃本次修改。「恢复默认」也需要保存才会生效。

默认在窄窗口优先展示主要列，可在表格底部点「显示全部列」，并横向滚动查看。也可以在布局编辑器关闭自动精简。一次性活动、长期活动与记录表单共用字号设置。设置单独保存在 `%APPDATA%\GoldenFleeceRecords\layout.json`。

## 本机记录与备份

数据保存在 `%APPDATA%\GoldenFleeceRecords\records.json`。第一笔记录保存后才会创建文件。换电脑或做完整备份时，退出 App，再复制这个文件。恢复时，先备份目标电脑原有文件，再将备份放到相同位置。一份完整备份包含活动、账户、DD、消费、规则和长期明细。界面上的 CSV 适合查看摘要。

分享发布页的压缩包或安装包即可。每位使用者独立记录，App 没有银行登录、远程同步或自动拉取银行流水功能。

## 从源码构建

Windows x64、Node.js 22.12+ 和 npm。在仓库目录依次运行：

```sh
npm ci
npm test
npm run package:win
npm run test:desktop
npm run test:layout
```

发布文件在 `release/`。桌面验收使用临时数据目录、合成记录和隐藏窗口。
